# FreshMart – Online Grocery Store

## About the Project
FreshMart is an online grocery shopping platform designed to make grocery shopping simple and convenient. Users can browse products, explore different categories, and manage their shopping experience through a user-friendly interface.

## Features
- User-friendly interface
- Browse grocery products
- Product categories
- Shopping cart functionality
- Store dashboard

## Technologies Used
- Python
- HTML
- CSS
- JavaScript

## Project Structure
The project contains the application files, frontend resources, and supporting files required to run FreshMart.

## How to Run
1. Download or clone this repository.
2. Extract the project ZIP file.
3. Open the project folder in VS Code.
4. Install the required dependencies.
5. Run the application using the appropriate Python command.
